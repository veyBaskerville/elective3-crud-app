# 🧩 Elective3 CRUD App (Dockerized Node.js + MySQL)

This is a simple **CRUD (Create, Read, Update, Delete)** web application built with **Node.js**, **Express**, and **MySQL**, and containerized using **Docker**.

The app allows users to:
- Add new records (items)
- Update existing records
- Delete records
- View all records in a table

## ⚙️ File Descriptions

### `index.html`
- Contains the **frontend UI**.
- Displays a table of records with buttons for **Add**, **Update**, and **Delete**.
- Uses JavaScript to communicate with the backend API via **fetch()** calls.

### `index.js`
- Main **server logic**.
- Built with **Express**.
- Connects to a MySQL database.
- Handles all CRUD routes:
  - `GET /api/items` → Fetch all items  
  - `POST /api/items` → Add new item  
  - `PUT /api/items/:id` → Update an item  
  - `DELETE /api/items/:id` → Delete an item  

### `package.json`
- Lists dependencies:
  - `express`
  - `mysql2`
  - `cors`
  - `body-parser`

### `Dockerfile`
Defines how the Docker image is built.

```dockerfile
# Use Node.js LTS version
FROM node:18

# Set working directory
WORKDIR /app

# Copy package files and install dependencies
COPY package*.json ./
RUN npm install

# Copy all project files
COPY . .

# Expose the app port
EXPOSE 3000

# Run the application
CMD ["node", "index.js"]
````

### `.dockerignore`

Prevents unnecessary files from being copied into the image.

```
node_modules
npm-debug.log
Dockerfile
.dockerignore
```

## 🧰 Prerequisites

* **Docker Desktop** installed and running
* **MySQL Server** (e.g., via XAMPP)

* Table: `items` (auto-created by Node.js on first run)

## 🪄 Setup Steps

### 1️⃣ Create `.dockerignore`

```bash
ni .dockerignore
```

Then add:

```
node_modules
npm-debug.log
Dockerfile
.dockerignore
```

### 2️⃣ Build Docker Image

In your terminal (inside the project folder):

```bash
docker build -t elective3-crud-app .
```

### 3️⃣ Run Docker Container

Run your container on port `3000`:

```bash
docker run -d -p 3000:3000 --name elective3-crud-container elective3-crud-app
```

### 4️⃣ Check if running

```bash
docker ps
```

If needed, see logs:

```bash
docker logs elective3-crud-container
```

You should see:

```
✅ Connected to MySQL
🚀 Server running on http://localhost:3000
```

### 5️⃣ Access the App

Open your browser:
👉 [http://localhost:3000](http://localhost:3000)

## ⚠️ Troubleshooting

**Error:** `ECONNREFUSED ::1:3306`
➡️ Ensure your MySQL (XAMPP) is running and accessible on port `3306`.

If using Docker for MySQL, update the host in `index.js`:

```js
host: 'mysql-db'  // use your MySQL container name
```
